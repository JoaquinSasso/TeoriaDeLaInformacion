## 📌 Descripción del Módulo

Esta carpeta contiene las actividades y resoluciones correspondientes a la segunda parte de la materia: **Codificación y Compresión de Datos**.

Incluye los ejercicios prácticos sobre fuentes de Markov y métodos de codificación (Huffman, Shannon, Fano), junto con el desarrollo de nuestro propio compresor de datos en Python (PPM-C con codificación aritmética), evaluado frente a herramientas estándar como ZIP y gzip.
